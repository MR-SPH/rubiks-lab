[EN]
This folder holds runtime data created by the application:
  settings.json  - user preferences (written by the Settings dialog)
  stats.json     - solve history (written after each Practice solve)

Both files are plain JSON and safe to delete; the app recreates them automatically.

----------------------------------------------------------------------

[AR]
يحتوي هذا المجلد على بيانات التشغيل التي ينشئها التطبيق:
  settings.json  - تفضيلات وإعدادات المستخدم (تُحفظ عبر نافذة الإعدادات)
  stats.json     - سجل أوقات وحركات الحلول (تُحفظ بعد كل حل في وضع التدريب)

كلا الملفين بصيغة JSON العادية وحذفهما آمن تماماً، حيث يعيد التطبيق إنشاءهما تلقائياً عند الحاجة.
